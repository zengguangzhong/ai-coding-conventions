# OpenClaw 配置

> OpenClaw 读取 `~/.openclaw/workspace/AGENTS.md`

OpenClaw 的 AGENTS.md 包含 Prism（棱镜）的完整人格和协作规则，是一个综合配置文件，不适合直接 hard link。

## 编码相关的规范

编码任务中，OpenClaw 应遵循 `core/` 和 `domains/coding/` 下的规范。OpenClaw 的 AGENTS.md 中"编码纪律"章节需与此仓库保持同步。

## 注意

OpenClaw 的 AGENTS.md 是一个独立的完整配置（包含人格定义、记忆系统、沟通方式等），不能简单拆分。编码/写作/研究规范部分保持内容一致即可。
